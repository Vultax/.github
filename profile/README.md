# Vultax

Prediction market research and developer tools that show their work.

We build **Vi** to make market evidence easier to inspect: exact market identity, source and observation times, explicit assumptions, and visible gaps in the data.

| Project | What it does |
| --- | --- |
| [Vi Assistant](https://github.com/Vultax/vultax-research-plugin) | Public MCP tools for market briefs, hypothetical price scenarios, and published research. [Try it](https://vultax.com/vi-mcp). |
| [Vi IQ developer preview](https://github.com/Vultax/vultax-iq-distribution) | An API gateway and integration packages for the Vi IQ feed. Marketplace subscriptions are not active. |
