# Security policy

Report a suspected vulnerability through the affected repository's **Security → Report a vulnerability** link when available. Please do not put exploit details, credentials, or private data in a public issue.

If private reporting is unavailable, use the contact route at [vultax.com/about](https://vultax.com/about) to request a secure channel. Include the affected repository and version, impact, and a minimal reproduction once a private channel is established.

We maintain the current default branch and current published release of active projects. Support for older releases is assessed case by case.
